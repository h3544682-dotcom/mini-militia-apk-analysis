# Mini Militia APK Modification & Analysis (Educational)

## Overview
This project is an educational deep-dive into the structure of an Android Package Kit (APK) for the game Mini Militia. The goal was to understand how mobile games are packaged and how game logic is handled.

## Technical Insights
*   **Structure Analysis:** Explored `AndroidManifest.xml` and `classes.dex` to understand game permissions and compiled logic.
*   **Integrity Checks:** Analyzed how the game uses file hashing (like MD5) to prevent tampering.
*   **Modding:** Altered internal resource files for personal use to understand how game mechanics are coded.

## Security Relevance
This project sparked my interest in **Reverse Engineering** and **Red Teaming**. By understanding how to modify an app, I gained insight into how developers must secure their apps against unauthorized changes.

**Disclaimer:** This was done purely for educational purposes on a personal device. No mods were distributed.
